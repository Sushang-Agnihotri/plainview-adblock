# Privacy policy: PlainView Ad Blocker

*Last updated: 7 November 2026*

**Short version: PlainView doesn't collect, store or share any information about you. Nothing leaves your device.**

## What PlainView processes, and where

| Data | What happens to it | Leaves your device? |
|---|---|---|
| Web requests your browser makes | Matched against PlainView's block rules **by the browser itself**. PlainView's code never sees the request URLs. | No |
| Address of the page you're on | Used in memory to choose which element-hiding rules apply and whether the site is on your allowlist | No |
| Class and id names on a page | Read by a small script and passed to PlainView's own background script to select hiding rules. Page text, form fields and passwords are never read. | No |
| Your settings (enabled lists, disabled sites, custom filters) | Saved in your browser's local extension storage | No |
| Count of pop-ups closed | A single number in local storage | No |

## What PlainView never does

- No analytics, telemetry, crash reporting or "usage statistics"
- No accounts or sign-in
- No network requests of its own. Filter lists are built into the extension and update only when the extension updates.
- No selling, sharing or transferring of any data, because none is collected
- No remote code: everything PlainView runs ships inside the extension package

## Removing your data

Uninstalling PlainView deletes all of its stored settings. You can also export or clear custom settings at any time from the settings page.
